Privacy Policy

This privacy policy applies to GTA6 Clips Uploader, a personal single-user application used only by its owner.

What the app does

The app uses the YouTube Data API solely to upload and manage videos on the owner's own YouTube channel, Gaming Community Hub. It is not offered to the public and is not used by anyone other than the owner.

Data collection

The app collects, stores, and shares no personal data of any other user. It does not have end users other than the owner.

Authentication

OAuth tokens used to access the YouTube Data API are stored only on the owner's machine and are used only to authenticate API requests for the owner's channel.

Google API Services User Data Policy

GTA6 Clips Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent via the owner's GitHub profile: github.com/vijapurkarfarukh-cloud.
